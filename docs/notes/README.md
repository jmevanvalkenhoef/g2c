# Design notes

Working notes from February 2026, before the escrow was built. They are kept
as the record of how the design was reached; the current design is in the
white paper and in `escrow/`.

- `DISCUSSION_SUMMARY.md`: the decision log, from the problem to the agreed
  architecture.
- `verification-greenlight-holdinvoices.md`: the check that Greenlight cannot
  run hold invoices, which ruled it out as the node backend before any code
  depended on it.
- `POC_PLAN.md`: the phased plan for the proof of concept.
